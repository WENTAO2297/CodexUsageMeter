# Codex Usage Meter

原生 macOS 菜单栏小组件，一眼查看 Codex 额度、VPN 流量和最近用量。

A native macOS menu bar app for Codex usage limits, VPN traffic, and activity.

[下载安装](#安装) · [数据与预测](#数据与预测) · [开发与验证](#开发与验证)

基于 JXA / AppKit 和原生 NSMenu，不占 Dock，不需要常驻用量网页，也不调用大模型维持监控。非官方个人项目，与 OpenAI 无隶属关系。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 菜单栏圆环 | 显示真实剩余额度，中心可切换数字或 Codex 图标；优先显示 Session，未返回时显示 Weekly。 |
| 额度与流量 | 紧凑圆环、重置倒计时和条件预测；缺失、过期、真实零值分别处理。 |
| 重置卡 | 日期胶囊、到期倒计时与寿命进度；只展示，不兑换或消耗。 |
| 用量活动 | 默认折叠，切换最近 7 天 / 30 天；Token 蓝柱与 VPN 绿线共用日期轴，各用独立纵轴，悬停查看两项用量。 |
| 原生交互 | 简体中文 / English、浅灰悬停、行内偏好设置；图表重开时重播动画，遵循系统“减少动态效果”。 |
| 日常操作 | 新建任务、询问 ChatGPT、重启小组件；不停止 Codex 任务。 |
| 独立运行 | 单实例、子进程恢复、登录启动和源码安装失败回滚；暂时读取失败保留已验证旧值。 |

菜单栏圆环剩余不高于20%时为橙色、不高于5%时为红色。面板绿色“有余量”需要足够历史支持，不代表保证够用；证据不足时的“进度正常”为中性提示。菜单栏中心变绿仅表示检测到近期本机任务记录，不是官方实时心跳。

## 安装

### 使用前了解

- 需要 macOS，以及已安装、已登录的 Codex；读取优先使用桌面应用内置 CLI，无需填写 API Key。
- 下载包运行无需 Node.js 或 Xcode；从源码构建需要 Node.js 和 Xcode Command Line Tools。读取还会使用系统的 `jq`、`sqlite3` 等工具。
- 二进制包含 Apple Silicon / Intel 架构，但尚未完成全部系统版本和设备的验证。
- MaoMaoYun 是可选集成，针对同名系统 VPN 服务；官网流量账号需要单独登录，不随客户端账号自动切换。

**VPN 行为请先确认：顶部开关当前只作动画预览，不连接或断开 VPN；但已有的启动、睡眠唤醒逻辑仍可能自动连接系统中名为 `MaoMaoYun` 的 VPN 服务。** 状态点反映真实连接状态，点击名称打开客户端。

### 直接下载安装包

前往 [GitHub Releases](https://github.com/WENTAO2297/CodexUsageMeter/releases/latest)，下载 DMG，打开后把 App 拖入“应用程序”；也可下载 ZIP 解压后移动 App。下载包不会自动配置登录启动，需要时可按 [Apple 官方说明](https://support.apple.com/zh-cn/guide/mac-help/mh15189/mac)手动添加。

**发布包仅使用 ad-hoc 签名，尚未完成 Developer ID 签名与公证。** 首次打开可能被 macOS 拦截。请先核对来源与 Release 中的 SHA-256；确认信任后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)在“隐私与安全性”中针对该 App 选择“仍要打开”，不要关闭系统安全保护。

> 安装包与 `main` 源码独立发布。本次工作日／周末预测更新已进入源码，尚未重新打包到现有 v1.0.0 Release；要使用这些更新，请从源码安装。

### 从源码安装最新版本

```sh
git clone https://github.com/WENTAO2297/CodexUsageMeter.git
cd CodexUsageMeter
zsh install-autostart.command
```

安装器会自动验证、构建、配置登录启动并重启小组件，不停止 Codex 任务。上一版保存在数据目录的 `Rollback` 中，安装失败时尝试恢复。

| 内容 | 默认位置 |
| --- | --- |
| App | `~/Applications/Codex Usage Meter.app` |
| 缓存、日志、回滚 | `~/Library/Application Support/CodexUsageMeter` |
| 登录启动配置 | `~/Library/LaunchAgents/com.wentao.codex-usage-meter-watch.plist` |

只构建、不安装：`zsh build.sh`。也可传入一个尚不存在的 App 目标路径。

### 首次连接 VPN 流量

点击 VPN 数据区的登录入口，在小组件自己的官网窗口登录，再选择“验证并连接”。这里只验证并绑定官网流量会话，不等于切换顶部预览开关。

密码只提交给官网，会话凭据保存在本 App 自己的钥匙串条目 `Codex Usage Meter · MaoMaoYun`。客户端与官网会话相互独立，后台不会自动弹出登录窗口。

### 卸载

```sh
zsh uninstall-autostart.command
```

卸载会停止小组件，删除 App、自启动配置、缓存、日志及回滚副本，不删除源码或 Codex 聊天。VPN 登录条目保留在钥匙串中，可自行删除，不影响客户端自己的登录。

## 数据与预测

### 数据从哪里来

| 数据 | 来源与口径 |
| --- | --- |
| Codex 额度 | 本机 Codex CLI 的 `account/rateLimits/read`；按实际返回窗口区分 Session / Weekly，不根据套餐名称猜测。 |
| Token 活动 | 与官方个人资料页相同的 `/wham/profiles/me` 日级统计，不从本机日志重算图表，不展示输入／缓存／输出分类。 |
| VPN 余额 | MaoMaoYun 官网 `getSubscribe`；重置倒计时使用 `reset_day`，不拿套餐到期日代替。 |
| VPN 用量 | 官网 `getTrafficLog` 的计费上传＋下载，不重复乘节点倍率；界面的 G 等单位按1024换算。 |

活动图按日期配对，不按数组位置拼接；两侧刻度按所选范围的峰值自动调整，并始终从零开始。今天是部分累计量，官网可能迟报或修订；缺报不补零，VPN 折线不跨缺口。官方累计 Token 总量不等于最近7天或30天合计，Token 也不是固定的额度或费用单位。

### 预测如何解读

- **Codex 周额度，第5版：** 以真实额度区间为主，近期数据有衰减权重；结合官网 Token 与真实快照重建最近28个已结束日期，作为低权重估算候选。有其他候选时，该估算权重最多20%，不增加实测覆盖或评分样本。周额度只显示状态提醒，不显示提前耗尽天数；Session 仍是短期情景。
- **VPN，第7版：** 在成熟、连续日量上组合7／14／最多35天的指数平滑视图，短期变化逐渐衰减。持续升降只修正近期，孤立高峰不外推整月，但仍保留在历史和波动情景中。典型路径耗尽时保留“提前约 N 天用尽”，总量和耗尽时间使用同一路径。
- **工作日／周末：** 当前预测日历固定为 `Asia/Shanghai`（UTC+8），区分周一至五和周六日，两项分别学习，不预设周末一定更少。样本不足时接近不修正；尚未单独建模法定节假日、调休或其他地区作息。VPN 只用经校验的上海日界学习星期规律，不给旧 UTC 记录重新贴日期标签。
- **可靠性：** 最近48小时的 VPN 日量不用于训练；原始记录、补齐估算和回测真值严格分离。过期、换账号、套餐变化、补额和重置均有边界检查；证据不足时显示中性进度或暂停预测，不编造精确日期。

这些是“未来使用习惯近似延续”的条件估计，不是够用保证。当前短历史回测尚不能证明月度准确率；日期对齐与星期修正的效果也不能混为一谈。详细方法、消融结果和限制见[上海日历预测验收](docs/FORECAST_DESIGN.md#2026-10-20-上海日历额度第5版vpn第7版)与[额度重建说明](docs/TOKEN_FORECAST.md)。

### 刷新与睡眠恢复

Token、VPN 余额通常每5分钟更新；打开菜单时，距上次查询至少1分钟才允许提前刷新。VPN 历史通常每6小时读取，后台最多保留180天，实际范围取决于官网仍返回什么；图表仍只展示7天／30天。切换图表范围不额外请求，HTTP 429 至少退避15分钟。

唤醒后先完成既有 VPN 重连、等待连接稳定，再优先同步流量。短暂失败有限重试，最多3次、3分钟，之后恢复常规刷新；暂时失败保留已验证旧值并标记过期，登录失效或会话变化则停止复用。

## 隐私与安全

- 使用本机已有 Codex 登录，不要求另填 API Key，不向预测服务上传用量；本地任务数据库仅作只读查询。
- 缓存按账号／会话隔离，只保留数字摘要，不保存聊天正文；目录权限0700、文件0600，原子写入。估算文件不会覆盖原始额度或 Token 图表。
- VPN 只读取本 App 自己的钥匙串条目，不读取客户端或其他浏览器认证；登录窗口使用临时 WebKit 会话。
- 官网请求正常校验 TLS、拒绝重定向并限制响应大小；凭据不进入命令行、环境变量或日志，不记录原始响应正文。
- 提交 issue 前请检查截图、日志和缓存；不要上传账号、认证文件、完整数据库或个人桌面截图。

## 已知限制

Codex 与 MaoMaoYun 内部接口没有公开兼容承诺，可能随版本变化。本机执行记录不是完整实时心跳，官网用量也可能延迟；离线测试不代表所有设备和系统事件均已验证。

当前未完成公证或广泛跨设备验证，仓库尚未指定开源许可证。源码不包含私人开发历史、认证缓存或旧版个人安装包；预编译 App 仅在 Releases 单独发布。
