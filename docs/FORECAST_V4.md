# 第4版预测改进与验收

目标：完整实现评分闭环、额度预测/周期进度区分、VPN近期变化检测和证据匹配的提示精度。保留当前288pt布局与查询频率，不引入大模型、外部服务、全局监听或任务控制。不自动发布GitHub。

## 必须证明的行为

1. 同时记录标准期限与当前实际显示期限，包含6.5天周额度和28天VPN预测；按实际期限分组评分。预测发出后候选及截止时刻不可被未来数据改写。
2. 睡眠后用真实前后余额约束目标时刻消耗，不线性插值成真值；宽区间保留为有界证据，不能当精确样本学习。补额、重置、耗尽、账号/套餐变化和时钟回退不能伪造成成功预测。
3. 模型权重以完成的同期限公共结果保守更新；保留简单均值基线，报告可用率、点误差/有界误差、风险误报漏报与有效独立样本。不能将日预测表现当成月预测准确率。
4. Codex有足够证据时显示真实预测结果；不足时明确显示周期进度来源。低余量、已耗尽、过期和重置状态优先。Session短期估计不冒充整个周期的够用保证。
5. VPN使用同账号同周期已报告余额变化检测近期持续变化。缺报不补零，一次突峰不单独确认新水平；不重复扣今日用量，不增加查询或在绘制中计算/扫描。
6. 严格日期精度需同时具备足够历史、模型一致性及窄耗尽情景范围；用户后续要求保留的粗估天数不提升算法精度标记。中文按用户要求统一短写为“提前约N天”，内部准入仍有区别。条件范围不称为已校准概率或置信区间。
7. 新缓存保留旧版回滚文件，迁移只继承校验通过的数字证据，不把v3评分当作v4已验证精度。账号/登录会话隔离、0700/0600与有界大小继续生效。
8. 验证包含纯算法反例、生产更新/缓存/菜单接线、双语原生渲染及首次/重新打开；完整verify通过后安装并检查运行版本。旧Release保持不变。

## 当前实现

- 期限：额度记录1/3/7天、实际剩余期限和提前1小时的独立探针；VPN记录1/3/7/14/28天、实际剩余期限和提前1天的独立探针。超过实际期限的标准目标不发出；同日同期限或同一绝对目标去重。
- 评分：实测前后端点给出目标消耗界。宽度超过max(0.5个百分点或0.1GiB，上界的10%)时保留为bounded、不学习；窄界仍保存actual=null，绝不伪装精确真值。补额/周期改变作废，耗尽为censored，正常额度重置最多提供物理上界。后续官方锚点可进一步缩窄额度界。
- 学习：同版本、同期限带、同候选公共结果，先从180天内挑不重叠目标，再保留最近56个。四个独立结果后才收缩更新，至少20个后才按期限归一化残差扩展情景；不称为概率校准。每次发出同时冻结未被变化检测调整的7天简单均值基线，便于后续配对比较。
- 近期变化：同周期余额每小时保留一个最近点。至少三个连续6–18小时间隔确认持续升速；降速至少36小时、连续多段。与成熟日记录的稳健正常范围/有收缩UTC星期模式比较。单段突峰、一个安静夜晚、重置或不同套餐不确认新水平。已证明的新速度影响接下来1–2天，整段持续仅为额外候选；不增加查询。
- 路径：连续两段块不跨缺日或环回；完整历史块保留内部累计形状，避免所有耗尽都错误挤到期限末端。近期升速在路径前端体现，不平均摊到整月。UTC星期候选按查询时刻的日内剩余时间计量。
- 提示：额度充分支持时才显示预测；不足时按周期进度显示“进度正常/消耗偏快”（按用户要求省略文案中的“周期”二字，内部来源与颜色不变）。VPN已有有效典型耗尽时刻时保留粗略时间，宽且两端都提前的情景显示范围；中文统一短写为“提前约N天用尽”或“提前约N–M天用尽”。严格门槛和粗估的precision/evidence标记、预测值及权重均不改；没有有效时刻时不编造天数。
- 按用户最新要求，Codex周额度取消提前耗尽的天数与范围，仅显示定性提醒；证据不足时恢复明确的周期进度来源，真实重置倒计时保留。内部预测、评分、候选、权重、查询频率和日志版本不变，VPN提前天数和Session短期提醒不受影响。
- 缓存：v4只读导入v3有效数字，旧文件不写回，旧成绩保留modelVersion=3，旧记录不占新版当天目标去重名额；损坏的v4不反复回退旧文件。180天/1200条/2MiB限制、账号会话隔离、0700/0600继续有效。

## 已核验与限制

- 纯回归：实际/临重置目标、睡眠宽/窄界、补额/重置/耗尽、未来结果隔离、140条月目标形成5个独立区间、版本隔离、一次突峰/持续升降、精度门槛及简单均值事前冻结。
- Foundation：真实原子保存、重启读取、v3原文保持不变、旧成绩标3、v4损坏不复用旧档、账号隔离与0700/0600。
- 原生绘制：中英文预测安全/风险/偏紧、具体/定性日期、弱证据周期来源、Session短期、旧值/缺值；实际文字宽度、图标、颜色和288pt/64pt几何通过。人工查看了中文风险与英文周期状态的生产视图离屏图。
- 真实长期校准、未来习惯突变与官网未报告消耗无法在本轮证明。睡眠后宽界可能永远不能缩窄，月度权重可能长期保持默认；这是缺失证据，不应强凑学习样本。真实接口的重置日仅天级精度，隐藏补额也可能不可观测。
- 180天最多容纳约6个不重叠28天目标，可以满足四个后的小幅权重学习，但不足20个残差结果。因此月度情景不会在这套保留规则下变成“20样本经验扩展”，更不能承诺等待一阵就会获得已校准的月度置信度。
